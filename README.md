# Programming

This repo documents my journey learning programming and software engineering as a **non-CS student** — from core fundamentals to interview-ready system design. It's both a personal log and a structured reference I keep coming back to.

## 👋 About This Repo

I didn't come from a computer science background, so this repo is my way of building that foundation deliberately — one topic at a time, with notes, code, and problem logs I can revisit. The long-term goal is to be interview-ready for **SDE roles at companies like Google and Microsoft**.

## 📂 Repo Structure

| Folder | What's Inside |
|---|---|
| [`Java/`](./Java) | Core Java, OOP fundamentals, Spring Boot, and certification prep (TCS Wings 1) |
| [`Data-Structures-and-Algorithms/`](./Data-Structures-and-Algorithms) | 12-week structured DSA prep using NeetCode, LeetCode, and Striver's Sheet |
| [`Low-Level-Design/`](./Low-Level-Design) | OOP design, SOLID principles, and design pattern practice on classic LLD problems |
| [`High-Level-Design/`](./High-Level-Design) | System design fundamentals and large-scale architecture problem practice |

Each folder has its own `README.md` with a detailed breakdown, progress tracker, and resource list.
